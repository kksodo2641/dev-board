# dev-board
Spring Boot 기반 실무형 개발자 커뮤니티 게시판

---

## 프로젝트 소개
개발자를 위한 커뮤니티 게시판 프로젝트

Spring Boot와 JPA를 활용하여 실무형 게시판 서비스를 구현한다.

회원, 게시글, 댓글, 검색, 파일 업로드 기능을 제공하며
실제 서비스 개발 과정과 Git 브랜치 전략을 함께 학습하는 것을 목표로 한다.

---

## 프로젝트 목표
- Spring Boot 기반 웹 애플리케이션 개발 경험
- JPA 활용 능력 향상
- Git 브랜치 전략 실습
- 인증/인가 기능 적용
- 테스트 코드 작성
- 실무 수준의 게시판 서비스 구현

---

## 주요 기능
### 회원
- 회원가입
- 로그인
- 로그아웃
- 회원정보 조회
- 회원정보 수정
- 회원탈퇴

### 게시글
- 게시글 작성
- 게시글 목록 조회
- 게시글 상세 조회
- 게시글 수정
- 게시글 삭제
- 조회수 증가

### 댓글
- 댓글 작성
- 댓글 수정
- 댓글 삭제
- 대댓글 작성

### 검색
- 제목 검색
- 작성자 검색
- 제목 + 작성자 검색
- 내용 검색 (향후 추가 가능)

### 기타
- 페이징
- 파일 업로드
- 파일 다운로드
- 좋아요 기능
- 마이페이지

### 관리자
- 회원 관리
- 게시글 관리
- 신고 게시글 관리 (향후 추가 가능)

---

## 도메인 규칙 (요약)
### 회원
- 이메일 로그인
- 닉네임 중복 불가
- 회원 탈퇴 시 소프트 삭제

### 게시글
- 작성자만 수정/삭제 가능
- 관리자 강제 삭제 가능
- 조회수 지원
- 첨부파일 다중 업로드 지원

### 댓글
- 대댓글 지원
- 소프트 삭제 적용

### 좋아요
- 게시글당 1회만 가능
- 취소 가능
