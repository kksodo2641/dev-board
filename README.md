# Dev Board
Spring Boot 기반 실무형 개발자 커뮤니티 게시판

---

## 프로젝트 소개

개발자를 위한 커뮤니티 게시판 프로젝트

Spring Boot와 JPA를 활용하여 실무형 게시판 서비스를 구현한다.

회원, 게시글, 댓글, 좋아요, 파일 업로드 기능을 제공하며, 실제 서비스 개발 과정과 Git 브랜치 전략을 함께 학습하는 것을 목표로 한다.

---

## 프로젝트 목표

- Spring Boot 기반 웹 애플리케이션 개발 경험
- JPA 활용 능력 향상
- Git 브랜치 전략 실습
- 세션 기반 인증 구현
- 인터셉터 기반 인증 처리
- 테스트 코드 작성
- 실무 수준의 게시판 서비스 구현

---

## 주요 기능

### 회원(Member)

- 회원가입
- 로그인
- 로그아웃
- 마이페이지 조회
- 회원정보 수정
- 회원탈퇴
- 세션 기반 로그인 인증
- Interceptor 기반 인증 처리
- 로그인 후 원래 요청 페이지 복귀

### 게시글(Board)

- 게시글 작성
- 게시글 목록 조회
- 게시글 상세 조회
- 게시글 수정
- 게시글 삭제
- 조회수 증가
- 공지사항(관리자 전용) 지원

### 댓글(Comment)

- 댓글 작성
- 댓글 수정
- 댓글 삭제
- 대댓글 작성

### 좋아요(BoardLike)

- 게시글 좋아요 등록
- 게시글 좋아요 취소

### 파일(UploadFile)

- 파일 업로드
- 파일 다운로드

### 검색(Search)

- 제목 검색
- 작성자 검색
- 제목 + 작성자 검색
- 내용 검색

### 관리자(Admin)

- 회원 관리
- 게시글 관리

---

## 도메인 규칙 (요약)

### 회원

- 이메일 로그인
- 닉네임 중복 불가
- 회원 탈퇴 시 Soft Delete 적용

### 게시글

- 작성자 또는 관리자만 삭제 가능
- 작성자만 수정 가능
- 게시글 Soft Delete 적용
- 조회수 지원
- 공지사항(관리자 전용) 지원
- 첨부파일 다중 업로드 지원

### 댓글

- 대댓글 지원
- Soft Delete 적용

### 좋아요

- 동일 회원은 동일 게시글에 한 번만 등록 가능
- 좋아요 취소 가능
